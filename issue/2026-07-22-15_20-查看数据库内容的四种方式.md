# 如何查看数据库内容（四种方式）

> 场景：后端用 Docker 起了 PostgreSQL，想查看/编辑里面的数据（用户、会话、消息、模板、用量等）。
>
> 关联文档：[本地启动与前后端对接指南](./2026-07-22-14_26-本地启动与前后端对接指南.md)

---

## 数据库连接信息（四种方式通用）

来自 `apps/api/docker-compose.yml` 与 `apps/api/.env`：

| 字段 | 值 |
| --- | --- |
| Host（主机） | `localhost` |
| Port（端口） | `5432` |
| Database（库名） | `wabao` |
| Username（用户名） | `wabao` |
| Password（密码） | `wabao` |
| 容器名 | `wabao-postgres` |

> 前提：数据库容器在运行。可用 `docker ps` 确认能看到 `wabao-postgres` 处于 `Up`；若没有，先在 `apps/api` 下执行 `docker compose up -d`。

当前库里共 **10 张表**：`users`、`conversations`、`messages`、`assistants`、`templates`、`creations`、`usage_records`、`feedbacks`、`moderation_records`、`refresh_tokens`。

## 方式一：Prisma Studio（最推荐 · 图形界面 · 零配置）

项目自带 Prisma，一条命令即可在浏览器可视化浏览/编辑所有表。

```powershell
cd d:\Vscode\store\wabao-ai\apps\api
pnpm exec prisma studio
```

- 启动后自动打开 **http://localhost:5555**（没弹出就手动访问该地址）。
- 左侧点表名 → 右侧表格展示数据，可：
  - **筛选**：顶部 `Filters` 按字段过滤（如 `messages` 按 `role = user`）。
  - **排序**：点列头（如按 `created_at` 倒序看最新消息）。
  - **看关联**：点关联字段可跳转到关联记录。
  - **改数据**：双击单元格编辑；`Add record` 新增；选中行 `Delete` 删除；改完点 `Save change`。
- 停止：在对应终端按 `Ctrl + C`。
- 优点：界面友好、中文显示正常、支持增删改查，日常首选。

## 方式二：命令行 psql（连进容器）

不想开界面时最快。

**交互式**（进入后可连续执行 SQL）：

```powershell
docker exec -it wabao-postgres psql -U wabao -d wabao
```

进入后常用命令：

```sql
\dt                      -- 列出所有表
\d messages              -- 查看 messages 表结构
SELECT * FROM users;     -- 查询用户
SELECT role, content, model FROM messages ORDER BY created_at DESC LIMIT 10;
\q                       -- 退出
```

**一次性执行**（不进交互，直接跑一条）：

```powershell
docker exec wabao-postgres psql -U wabao -d wabao -c "SELECT count(*) FROM users;"
```

常用速查示例：

```powershell
# 各表行数总览
docker exec wabao-postgres psql -U wabao -d wabao -c "SELECT 'users' t, count(*) FROM users UNION ALL SELECT 'messages', count(*) FROM messages UNION ALL SELECT 'templates', count(*) FROM templates;"

# 最近 5 条消息
docker exec wabao-postgres psql -U wabao -d wabao -c "SELECT role, left(content,20) content, model, created_at FROM messages ORDER BY created_at DESC LIMIT 5;"
```

> 注意：在 Windows PowerShell 里查询结果中的中文可能显示成 `?`，这只是终端编码问题，**库里数据本身是正常的**。介意的话用方式一/方式四查看，或给 PowerShell 设置 UTF-8。

## 方式三：Docker Desktop 图形界面

1. 打开 Docker Desktop → 左侧 **Containers**。
2. 找到 `wabao-postgres` → 点进去。
3. 顶部 **Exec** 标签 → 进入容器终端 → 输入：
   ```bash
   psql -U wabao -d wabao
   ```
   然后即可用方式二里的 SQL 命令。
4. **Logs** 标签可查看数据库运行日志（排障用）。

> 优点：不用记 `docker exec` 命令，点点鼠标即可进容器。

## 方式四：专业 GUI 客户端（DBeaver / TablePlus / Navicat）

适合经常看数据、写复杂 SQL 的人。以免费的 **DBeaver** 为例：

**安装：**

```powershell
winget install -e --id DBeaver.DBeaver.Community
```

**新建 PostgreSQL 连接，填写：**

| 字段 | 值 |
| --- | --- |
| Host | `localhost` |
| Port | `5432` |
| Database | `wabao` |
| Username | `wabao` |
| Password | `wabao` |

连接后即可在左侧树浏览表、双击查看数据、执行 SQL、导出 CSV 等。

> 其他同类客户端：TablePlus、Navicat、DataGrip、pgAdmin，连接参数一致。

---

## 四种方式怎么选

| 方式 | 适合场景 | 门槛 |
| --- | --- | --- |
| ① Prisma Studio | 日常浏览/改数据，最省事 | 零配置，推荐 |
| ② psql 命令行 | 快速查一条、写脚本、CI | 需会点 SQL |
| ③ Docker Desktop Exec | 不想记命令，图形进容器 | 零命令 |
| ④ GUI 客户端 | 重度使用、复杂查询、导数据 | 需装客户端 |

---

> 一句话建议：**平时用「方式一 Prisma Studio」**，排障或写脚本时用「方式二 psql」。
